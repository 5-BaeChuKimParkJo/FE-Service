# 내 경매

마이페이지 **내 경매**(`/mypage/sales`)에서 내가 등록한 경매를 관리한다.
이번 범위는 조회다. 경매 수정·취소·결제 실행 기능을 추가하지 않는다.

- 대기·진행·종료·숨김·취소와 전체 수를 표시한다. 요약은 검색 결과가 아니라 본인
  전체 경매 기준이며 검색 결과 수·페이지는 별도로 보여준다.
- 제목 검색, 상태 필터, 최근 등록/마감/가격 정렬과 20개 단위 페이지를 제공한다.
  검색 폼을 제출하면 첫 페이지로 이동하고 페이지 링크는 조건을 유지한다.
- 가격은 서버의 문자열을 유지한다. 현재 최고가(입찰 전에는 시작가), 입찰 기록 수,
  한국시간(KST) 마감을 표시한다. 종료 자체가 판매·결제 완료를 뜻하지 않는다.
- 숨김/취소 경매도 본인 목록에 표시하지만 공개 상세로 연결하지 않는다. 삭제 경매는
  제외한다. API 오류, 등록 없음, 조건 무결과, 범위 초과 페이지를 구분한다.
- 새로고침으로 상태를 갱신한다. 조회·필터·페이지는 일반 GET 탐색으로 실행한다.
  클라이언트 전환에서 이전 결과가 남는 현상을 재현해 전체 페이지 조회로 통일했다.
  다른 기존 경매 화면의 탐색 방식은 변경하지 않는다.

전용 조회 API는 검증된 JWT 소유자를 사용한다. 클라이언트에는 화면 필드만 보내고,
이전 catalog API에서 URL에 사용하던 회원 cookie 값을 소유자로 신뢰하지 않는다.
실패는 고정 메시지로 보여주며 빈 성공으로 바꾸지 않는다. 만료 쿠키 복구는 기존
공통 signOut 후 로그인 이동을 사용한다. 관련 컴포넌트 이름을 SessionSignInButton으로
일반화했고 관심 경매에도 같은 동작을 유지한다.

## 로컬 재현

첫 터미널:

```powershell
$env:API_URL='http://127.0.0.1:34425'
$env:NEXT_PUBLIC_DEPLOYMENT_MODE='homelab'
pnpm build
pnpm exec next start -p 34727 -H 127.0.0.1
```

두 번째 터미널에서 로컬 fixture API를 포함한 검증을 실행한다:

```powershell
$env:E2E_BASE_URL='http://127.0.0.1:34727'
pnpm exec playwright test e2e/my-sales.spec.ts --workers=1 --retries=0
```

fixture 토큰은 로컬 전용 문자열이다. 실제 경매를 만들거나 입찰/결제하지 않는다.
상태·가격은 조회 시점 기준이며 별도 요청 사이의 페이지 구성을 고정하지 않는다.
offset 조회는 최대10000페이지다. 대규모 목록에는 커서 방식 등을 별도로 검토한다.
