# 포트폴리오 체험 순서

기준일: 2026-10-29. 실제 배송·거래 없이 테스트하는 경매 서비스다.
데모 계정 비밀번호나 관리자 자격 증명을 문서에 적지 않는다.

## 1. 로그인 없이 둘러보기

운영자가 안내한 고객 웹에서 경매 목록, 상세와 최근 24시간 인기 경매를 확인한다.
인기 경매는 실제 활동을 집계하므로 빈 목록이나 적은 순위가 정상일 수 있다.
데모 보충으로 조회·입찰 수를 만들지 않는다.

공개 NPM 도메인을 제공받지 않았다면 운영자에게 접근 경로를 확인한다. Tailnet
전용 주소는 Tailscale 연결이 필요하다. 비공개 GitOps에 [접속·운영 안내](https://github.com/chuman0216/cncn_private/blob/main/README.md)가 있다.

## 2. 체험 계정으로 입찰

1. 홈 또는 로그인 화면의 **체험 계정으로 입찰하기 / 시작하기** 버튼을 누른다.
2. 제목에 `[DEMO]`가 있고 시간이 남은 경매를 고른다. 자동 보충은 5분 주기이며
   서버 설정과 템플릿이 정상일 때 활성 데모를 유지한다. 특정 UUID를 영구 링크로 사용하지 않는다.
3. 화면에서 허용하는 금액으로 한 번 입찰한다.
4. 접수 후 저장 결과가 확인되어 성공 상태와 입찰 내역에 반영되는지 확인한다.

공유 체험 계정이 이미 최고 입찰자이면 연속 입찰이 거절될 수 있다. 판매자 본인도
입찰할 수 없다. 타임아웃은 저장 실패 확정이 아니므로 연타하지 말고 내역을 먼저 확인한다.
**내정보 → 참여한 거래**에서 경매별 내 최고 입찰가와 입찰 기록을 확인한다.
제목 검색·상태 필터로 찾고, 종료 경매는 **상세 · 결제 확인**으로 이동한다.
이 목록의 종료 표시 자체가 낙찰이나 결제 완료를 뜻하지는 않는다.
관심 있는 경매는 상세의 **관심 등록**으로 저장하고 **내정보 → 관심 경매**에서 다시
확인한다. 같은 계정의 다른 기기에도 유지되며 필요하면 **관심 해제**한다.
직접 등록한 경매는 **내정보 → 내 경매**에서 전체/상태별 수, 현재 가격·입찰 횟수·
마감을 확인한다. 제목·상태로 검색하고 정렬·페이지·새로고침을 사용할 수 있다.
조회 전용이며 출품이 없는 계정에는 빈 목록이 정상이다. 숨김/취소는 본인에게만
표시하고 경매 종료를 판매 완료로 해석하지 않는다.
관리자에게 빠른 체험을 요청하면 **데모 경매 생성 → 5분**으로 새 경매를 준비할 수
있다. 생성 직후부터 시간이 흐르므로 고객 화면 링크를 열고 마감 전에 입찰한다.
체험 안내의 단계와 남은 시간을 따라가면 마감 후 화면이 한 번 갱신된다.
결과가 늦게 보이면 **결과 새로고침**을 누른다. 자동 보충 데모는 다음 날 종료한다.

## 3. 낙찰자 테스트 결제

종료된 경매에서 **현재 로그인한 계정이 낙찰자일 때만** 결제 화면을 체험할 수 있다.
대상 경매가 없으면 이 단계는 운영자와 사전에 준비한다. 관람 목적으로 기존
경매의 입찰·결제 상태를 DB에서 바꾸거나 강제로 초기화하지 않는다.

- 결제는 Toss 테스트 환경이다. 클라이언트 리다이렉트만으로 결제 완료가 되지 않는다.
- 서버가 검증한 고정 주문 금액을 확인하고 테스트 창을 진행한다.
- 결과가 불명확하면 결제 상태 확인을 사용한다. 새 주문을 열어 반복 결제하지 않는다.
- 개인 휴대폰·앱 인증이 필요한 단계는 체험자가 직접 수행한다.

## 4. 관리자 화면 확인

관리자 접근 권한은 별도로 요청한다. 고객 체험 계정에 관리자 권한을 부여하지 않는다.

| 메뉴               | 확인할 내용                                                    |
| ------------------ | -------------------------------------------------------------- |
| 운영 개요          | 종료 임박·결제 미시작·기한 경과·결과 미확정 수와 필터 바로가기 |
| 경매               | 상세 이미지·판매자·입찰 내역, 숨김·복원·강제 종료와 사유       |
| 결제               | 낙찰자 닉네임·UUID, 금액·주문·상태, 전액 취소와 표준 사유      |
| 관리 이력          | 운영자·시각·사유·처리 결과, 해당 상세 화면으로 이동            |
| 내부 대시보드 링크 | Argo CD·Headlamp·Kafka UI·MinIO 콘솔로 이동                    |

관리자 변경은 실제 상태와 운영 이력을 남긴다. 취소·강제 종료는 운영자와
합의한 테스트 대상에서만 실행한다. 대시보드의 기한 경과 표시는 자동 취소가 아니다.
내부 콘솔 링크는 Tailscale과 각 콘솔의 인증이 필요하다.

## 범위와 알려진 제약

현재 홈랩은 채팅·SSE 알림·상품 서비스·정산을 배포하지 않는다. 검색은 이벤트 반영에
시간이 걸릴 수 있다. 장애 시 자동 백업·HA로 계속 운영되는 환경도 아니다.
체험 결과를 고부하 성능 검증이나 실제 상거래 실적으로 해석하지 않는다.
