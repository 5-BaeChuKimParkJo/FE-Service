# 대기 경매 수정·취소

내 경매의 **경매 관리**에서 제목·설명·시작가·시작/종료 시각을 수정하거나 출품을 취소한다.
사진·카테고리·태그·거래 방식은 이번 범위에서 변경하지 않는다. KST 정각 일정, 최소1시간,
제목5–100자/설명1000자, 시작가1000원 이상과 기존 이벤트의 안전 정수 상한을 사용한다.

취소 사유는 등록 정보 오류/상품 판매 불가/경매 일정 변경/개인 사정/기타다. 기타만 수기
설명1–200자를 받는다. 취소 확인 후 상태를 바꾸며 삭제하지 않고 최근20건의 판매자 변경
이력에 시각·사유·이전/변경 값을 남긴다. 이미 시작했거나 입찰·거래·숨김·취소 상태면 조회만 한다.

기존 관리자 PUT을 확대하지 않고 `/auctions/:uuid/seller` GET/PATCH와 `.../cancel` POST를
사용한다. JWT 소유자만 접근하고 다른 사람/삭제 경매는404다. 공개 legacy PUT/DELETE는
관리자로 제한했다. 기존 클라이언트가 판매자 DELETE를 사용했다면 새 취소 경로로 이전해야 한다.
내부 거래 완료 호출은 변경하지 않는다.

서버는 행 잠금 이후 상태와 버전을 다시 확인한다. DB 시계가 시작 시각을 넘은 경우 SQL
조건부 UPDATE도 거부한다. 이전 버전이나 중복 요청은409이며, 화면은 최신 상태를 다시
확인하도록 안내한다. 요청 시간 초과는 실패로 단정하거나 자동 재시도하지 않는다.
성공 후 문서 탐색으로 서버 상태와 이력을 새로 읽는다. 취소 상태와 이력·Outbox는 같은
트랜잭션에 기록되고, 기존 검색 삭제 이벤트를 사용한다. 실제 입찰·결제를 만들지 않는다.

## 로컬 재현

운영 자격 증명이나 DB를 복사하지 않는다. fixture 전용 API를 사용해 빌드/실행한다.

```powershell
$env:API_URL='http://127.0.0.1:34427'
$env:NEXT_PUBLIC_DEPLOYMENT_MODE='homelab'
$env:COOKIE_SECURE='false'
pnpm build
pnpm exec next start -p 34729 -H 127.0.0.1
```

다른 터미널:

```powershell
$env:E2E_BASE_URL='http://127.0.0.1:34729'
pnpm exec playwright test e2e/seller-management.spec.ts --workers=1 --retries=0
```

fixture에서만 수정·취소를 실행한다. 운영 검증은 기존 판매자 샘플과 구매자의 읽기 접근을
확인하며 기존 경매·입찰·결제·이미지를 초기화하지 않는다.
